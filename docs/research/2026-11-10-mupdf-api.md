# MuPDF.js API for phase 2 (2026-11-10)

`mupdf` 1.28.6, loaded with `await mupdf()` from `src/lib/engine/mupdf.ts` (`m` below).
Every call here was run in Node 22 against the corpus or a generated file. Coordinates
are MuPDF page space: points, origin top-left of the page's bounds, y down, `/Rotate`
not applied (use `page.getTransform()` / `getBounds()` to map from stamp fractions).

## Documents and pages
- `m.Document.openDocument(bytes, 'application/pdf').asPDF()` or `new m.PDFDocument(bytes)`.
- Password: `doc.needsPassword()`; `doc.authenticatePassword(pw)` returns 0 wrong, 2 user, 4 owner (bit flags).
- `doc.countPages()`, `doc.loadPage(i)` (PDFPage), `page.getBounds()` → `[x0,y0,x1,y1]` (CropBox),
  `page.getBounds('MediaBox')`, `page.getTransform()` (PDF space → page space, e.g. `[1,0,0,-1,0,792]`).
- Save: `doc.saveToBuffer('garbage=compact,compress').asUint8Array().slice()` (copy: the view is
  into wasm memory). Other options seen working: `garbage=deduplicate`, `compress-images`,
  `compress-fonts`, `clean`, `sanitize`, `incremental`. `decrypt` is deprecated: use `encrypt=none`.
  Our qpdf finalize still does compression/encryption; MuPDF stages only need `garbage=compact`.

## Structured text
- `page.toStructuredText('preserve-whitespace')` → `st.asText()`, `st.asJSON()`.
- Boxes: `st.walk({ beginLine(bbox, wmode, dir), onChar(c, origin, font, size, quad, color), endLine(), onImageBlock(bbox, matrix, image), onVector(bbox, flags, color) })`.
  `quad` is 8 numbers (ul, ur, ll, lr corners). Options are a comma list; valid names include
  `preserve-images`, `preserve-whitespace`, `preserve-ligatures`, `preserve-spans`, `accurate-bboxes`,
  `mediabox-clip`, `ignore-actualtext`, `dehyphenate`, `vectors` (needed for `onVector`).
  An unknown option throws "Unused stext arguments found".
- `page.search(needle)` / `st.search(needle)` → `Quad[][]`.

## Rendering
- `page.toPixmap(m.Matrix.scale(s, s), m.ColorSpace.DeviceRGB, false /*alpha*/, true /*annots+widgets*/)`.
- `pix.getWidth()`, `getHeight()`, `getNumberOfComponents()` (3 for RGB), `getStride()`,
  `getPixels()` (Uint8ClampedArray view, row-major, no padding seen), `asPNG()`, `asJPEG(q)`.

## Redaction
- `const a = page.createAnnotation('Redact'); a.setRect([x0,y0,x1,y1]);` (page space).
- `page.applyRedactions(true /*black boxes*/, m.PDFPage.REDACT_IMAGE_PIXELS, m.PDFPage.REDACT_LINE_ART_REMOVE_IF_COVERED, m.PDFPage.REDACT_TEXT_REMOVE)`.
  Other values: `REDACT_IMAGE_NONE|REMOVE|PIXELS|UNLESS_INVISIBLE`, `REDACT_LINE_ART_NONE|REMOVE_IF_COVERED|REMOVE_IF_TOUCHED`, `REDACT_TEXT_REMOVE|NONE`.
  Per annotation: `annot.applyRedaction(black, image, lineArt, text)`.
- Verified on a generated page: text under the box gone from stext, photo pixels under it
  black (the image stays, blacked), the line removed, the **link removed**, but a **Square
  annotation under the box survived**: the redact stage must delete other annotations itself.
- Annotations: `page.getAnnotations()` (excludes links and widgets), `a.getType()`, `a.getRect()`,
  `a.getFlags()`, `page.deleteAnnotation(a)`. Links: `page.getLinks()`, `l.getBounds()`,
  `l.getURI()`, `page.deleteLink(l)`, `page.createLink(rect, uri)`.

## Widgets (form fields)
- `page.getWidgets()` → PDFWidget[] (one per widget; a radio group has several with one name).
- `w.getFieldType()`: one of `PDFWidget.WIDGET_TYPES` = `widget button checkbox combobox listbox radiobutton signature text`.
  Also `isText()`, `isCheckbox()`, `isRadioButton()`, `isChoice()`, `isListBox()`, `isComboBox()`, `isPushButton()`.
- `w.getName()` (fully qualified), `w.getLabel()` (/TU, **falls back to the name** when there is none),
  `w.getValue()`, `w.getFieldFlags()` (`PDFWidget.FIELD_IS_READ_ONLY`, `TX_FIELD_IS_MULTILINE`,
  `CH_FIELD_IS_MULTI_SELECT`, …), `isReadOnly()`, `isMultiline()`, `isComb()`, `isPassword()`,
  `getMaxLen()` (0 = none), `w.getRect()`, `w.getOptions()` / `w.getOptions(true)` (export values).
- Set: `w.setTextValue(s)`, `w.toggle()` (checkbox; radio: turns that widget on), `w.setChoiceValue(v)`
  (single value). Multi-select lists: no API; write `/V` as an array via
  `w.getObject().put('V', arr)` with `arr = doc.newArray(); arr.push(doc.newString(v))`, then `w.update()`.
  Always `w.update()` after setting to regenerate the appearance.
- Values read back: checkbox `'Yes'`/`'Off'` (the on-state name, not always "Yes"); radio returns the
  **appearance state name** of the chosen widget, which can differ from the option shown
  (pdf-lib radios: states `0`,`1` with `/Opt [red blue]`, so `getValue()` is `'1'` for "blue";
  `getOptions()` returns `['red','blue']`): map via /Opt index.
- Flatten: `doc.bake(true /*annots*/, true /*widgets*/)`; after a save and reopen there are no
  widgets, no annotations and no /AcroForm, and the text answers are page text.

## Images
- No image list API: walk objects `for (i = 1; i < doc.countObjects(); i++) { o = doc.newIndirect(i); if (o.isStream() && o.get('Subtype').asName() === 'Image') … }`
  (note: `isStream()` on the indirect ref; `o.resolve().isStream()` is false). Or walk page `/Resources/XObject`.
- Decode: `img = doc.loadImage(o)`; `getWidth/Height()`, `getBitsPerComponent()`,
  `getNumberOfComponents()`, `getColorSpace()?.getName()`, `getImageMask()`, `getMask()`, `img.toPixmap()`.
- Resample: no `Pixmap.scale`; `pix.warp([[0,0],[w,0],[w,h],[0,h]], nw, nh)` works, or draw with
  `new m.DrawDevice(m.Matrix.identity, dst).fillImage(img, [nw,0,0,nh,0,0], 1)` then `close()`.
- Re-encode: `pix.asJPEG(quality)` → `nref = doc.addImage(new m.Image(bytes))`.
- Replace in place (every reference keeps working):
  `o.writeObject(nref.resolve()); o.writeRawStream(nref.readRawStream()); doc.deleteObject(nref)`.
  Verified: dictionary and stream replaced, page renders, file shrank.

## Not in this version
`Pixmap.scale`, a multi-value `setChoiceValue`, an image enumeration helper, removal of non-link
annotations by `applyRedactions`, and stext option `collect-vectors` (it is `vectors`).
