# Research summary — 2026-11-09

Two web research passes informed the plan. Versions are from npm on this date.

## Landscape

- **BentoPDF** (AGPL, ~110 tools, in-browser WASM) already covers most single
  operations and is self-hosted by universities. Mostly one tool per page; open
  issues on mobile editing, OCR freezes on large files, slow loads in Edge.
- **Stirling-PDF** needs a Java server for heavy work, is open-core, and moves
  features behind paid plans.
- **iLovePDF, Smallpdf, Sejda web, PDF24 web** upload files; free tiers have caps or ads.
- **Built-ins:** Firefox can annotate and place a saved signature; Edge can type,
  draw and fill forms; neither reorders pages. macOS Preview is the closest thing
  to a single workspace, and is Mac-only.
- **Gap:** no free in-browser tool offers one workspace that combines page
  arranging with fill-and-sign on the same document. Compress-to-target-size is
  also mostly missing.

## Libraries

| Library | License | Role here | Notes |
|---|---|---|---|
| qpdf (wasm, `@neslinesli93/qpdf-wasm`, 1.3 MB) | Apache-2.0 / ISC wrapper | page operations, repair, encryption, `--check` | CLI interface only |
| PDF.js (`pdfjs-dist`) | Apache-2.0 | rendering, re-open check | best-tested renderer |
| `@cantoo/pdf-lib` | MIT | stamps, image/blank page creation | maintained fork; original pdf-lib is dead since 2021; parser is weak on damaged files, so inputs are normalized by qpdf first |
| MuPDF.js (10.4 MB) | AGPL-3.0 | phase 2 redaction, form flattening | reason the repo is AGPL |

Verdicts used for scope. Safe: merge, split, delete, reorder, rotate, insert,
images to PDF, lossless compression, known-password add/remove, metadata strip.
Careful (phase 2, with checks): redaction, form fill/flatten, image downsampling,
stamps on rotated or cropped pages. Avoid in the browser: PDF/A, PDF to Word,
Office to PDF, XFA.

## Platform constraints

- iOS Safari caps a canvas at about 16.7 megapixels and limits total canvas
  memory; release canvases by resizing to 0×0 and limit concurrent renders.
- File System Access pickers are Chromium-only; fall back to file input and download.
- Web Share Target needs an installed PWA on Chromium; iOS has no equivalent.
